# Workspace instructions

This workspace contains several independent experiments. Legacy of Terra lives in
`legacy of terra/`; keep its changes inside that directory unless a workspace
change is explicitly needed. Preserve unrelated files and existing user work.

Read [the project's instructions](legacy%20of%20terra/AGENTS.md) before changing
Legacy of Terra. Run its commands from the project directory and quote paths
containing spaces. Project design and implementation status belong in the project
documents, not in this workspace file.
